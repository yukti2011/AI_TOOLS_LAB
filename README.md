# AI Tools Lab

A practical laboratory repository exploring Git, GitHub, version control, and AI-assisted software development.

## About

This repository contains exercises completed as part of the Artificial Intelligence Tools and Applications Lab. It demonstrates version-control workflows and the use of AI coding assistants for programming, documentation, debugging, and code improvement.

## Features

- Git and GitHub version control workflow
- Feature branch development
- Bubble Sort implementation
- Palindrome checker
- Word counter
- Celsius to Fahrenheit converter
- AI-assisted code generation and documentation
